Mini Library System

What it does: Add, borrow and return books. Saves the data to JSON and CSV so nothing is lost when the program closes.

What I used: Python lists and dictionaries, the json and csv modules, functions and a small menu loop.

What was hard: Keeping the JSON and CSV files in sync, and writing the borrow logic so a book already borrowed cannot be borrowed again.

Fest Trophy

What it does: Takes the points each team scored, adds them up and picks the winning team.

What I used: Dictionaries to hold team scores, max() to find the top score, and loops to read the input.

What was hard: Handling ties — two teams with the same points had to be printed together instead of picking one.
